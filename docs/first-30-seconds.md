# 从零到第一段30秒作品

目标是一段能保存、能回听、有一个清晰主题的小样，不是一天学会全部制作。用普通电脑和耳机即可开始手工路线；AI本地路线的GPU要求另见[部署指南](deployment.md)。耗时因工具、网络、模型和练习而异，不承诺固定分钟数出歌。

## 先懂六个词

- **节拍/BPM**：每分钟的拍数，决定快慢
- **小节**：把拍子分组。4/4拍的一小节有四拍
- **旋律**：可以哼出来的那条音高线
- **和弦**：几个音一起响，为旋律提供背景
- **音轨**：单独放一种乐器或人声的“层”
- **MIDI与WAV**：MIDI主要记录何时弹什么音；WAV保存实际声音。保存MIDI不代表导出了能直接播放的完整音频

## 第一步：只选一个小主题，写四行词

例如“夜晚散步”。每行先用相近长度的日常短句，不强求复杂押韵；大声读一遍，删掉难唱的长词。需要帮忙时用[原创示例与提示模板](../examples/first-song.md)，不要拿已发行歌曲的完整歌词替换。

选择下面一条分支，不要同时安装多个软件。

## 分支A：不依赖AI的30秒旋律

1. 打开[BeepBox](https://www.beepbox.co/)，从一个空白作品开始，保留一种主旋律音色和一种鼓音色
2. 选择4/4拍、96 BPM。12小节约为30秒（12×4÷96×60）；此为目标结构，不代表软件预设已替你设好
3. 先做4小节：每小节底鼓落在第1、3拍，军鼓在第2、4拍。不会辨认鼓音色时先用任意两种明显不同的打击声
4. 主旋律先选3到5个听起来顺耳的音，每小节只放少量音符，空白也是音乐
5. 把4小节复制成三段；第二段只改最后一个音，第三段末尾留一拍空白作为结束
6. 回听，删掉抢耳的音，调低过响的轨道。按当前菜单保存作品链接或导出音频；分享链接会把作品分享出去
7. 想要MIDI或中文编辑界面，可改用[signal](https://signalmidi.app/edit)，先熟悉时间横轴和音高纵轴，再导出MIDI/WAV

验收：能听到重复且有一点变化的主题，结尾不是意外截断，保存后可以重新打开。作品可以先没有人声。

## 分支B：让AI试唱四行歌词

1. 从[ACE-Step官方README](https://github.com/ace-step/ACE-Step-1.5)进入其提供的体验链接，先看该服务当前条款与费用；不要向陌生“整合包”输入账户或私密录音
2. Simple模式适合从描述开始；如果你要控制具体四行歌词，优先了解Custom模式。低显存配置可能关闭负责规划/写词的LM
3. 使用[示例](../examples/first-song.md)中的歌词和简单风格；如果界面提供时长选项，先设约30秒。不支持该短时长时，先生成较短可用段，再剪取自然完整的一段，不保证固定长度精确命中
4. 保存提示词、歌词、模型ID、版本、seed和结果。生成三个版本，每次只改一个条件
5. 逐句检查：是否漏字、多字、发音不清、重音别扭、伴奏淹没人声。遇到问题先缩短歌词或减少风格要求，不立即升级更大模型
6. 三个版本都不理想时，再比较HeartMuLa；想精细改音高/和弦时才进入YuE2或OpenUTAU路线

验收：主题和情绪明确，四行词大致能听清，保存一份约30秒可回听小样。记录失败也算实验结果，不用“精选演示好听”替代自己的判断。

## 分支C：自己唱，保留自己的声音

1. 用前面做出的伴奏，或其他明确有权使用的伴奏；打开[Audacity官方发布版](https://www.audacityteam.org/)
2. 戴耳机，选择正确麦克风，先录5秒并回听；若波形削顶/声音刺耳，降低输入音量再试
3. 导入伴奏，在新轨录四行词；不满意就重录一句，不急着安装修音插件
4. 留存原始录音；剪去明显空白、调整人声与伴奏相对音量，保留自然收尾
5. 保存可编辑工程，再导出WAV。工程文件和导出音频用途不同，二者都保留

验收：能听清人声，耳机伴奏没有明显串入麦克风，开头结尾自然，没有明显爆音。

## 最后保存一个作品包

建议包含：歌词、创作意图、工程文件、最终WAV、模型/工具版本、提示词与seed（若适用）、素材来源、用途许可核查记录。使用[作品记录模板](../examples/project-log.md)。先私人回听和改进，公开或商业发行前完成[权利检查单](license-matrix.md)。

## 下一次只增加一种能力

想让旋律更好记：练习重复与变化。想伴奏更丰富：LMMS中添加贝斯轨。想让虚拟歌手按自己的音符唱：OpenUTAU配兼容声库。想学习节奏：Hydrogen。不要把“装好了更多工具”当成完成更多作品。
