# Music Creator 创作工具使用说明

这是一款在电脑上生成、在电脑或同一 Wi-Fi 的安卓浏览器上操作的音乐工作台。电脑需要开着。

## 在这台电脑上开始

1. 打开正式交付目录，双击 `启动音乐工作台.cmd`，保留启动窗口。
2. 浏览器打开窗口显示的电脑地址，输入窗口中的 6 位配对码。等待页面显示“音乐模型已连接”。
3. 点击“做 BGM”或“写一首歌”。第一次建议做 30 秒配乐或 1 分钟歌曲。

模型首次加载可能需要几分钟。工作台提前打开时会提示尚未连接；页面会自动更新。此启动入口不安装软件、不修改已有环境。

## 用安卓手机操作

电脑与手机连接同一家庭 Wi-Fi，在安卓 Chrome 等现代浏览器输入启动窗口中的“手机地址”，输入同一个配对码即可。无需在手机安装模型。可将网页添加到手机主屏幕，作为访问快捷方式；它仍需电脑在线。

若连接不上，先确认电脑页面可用，检查是否连接了访客 Wi-Fi、路由器是否隔离设备，以及 Windows 是否允许此 Python 在**专用网络**访问。工具不会自动更改防火墙，也不配置公网端口转发。不要在公共 Wi-Fi 上使用局域网模式。

## 做一段 BGM

选“做 BGM”，写明画面、用途、情绪和乐器，例如：“小狗在草地奔跑的短视频，温暖轻快，木吉他和简单鼓点，音乐别盖过旁白，结尾自然收束。”选择风格、情绪、时长，再生成。

作品出现在“我的作品”。完成后可以试听、下载 WAV，导入剪映等剪辑软件。需要不同版本时点击“沿用这个想法”，修改后再次生成。

## 写一首歌

选“写一首歌”，写主题。可以自己填歌词，也可以选择“先让 AI 根据主题写草稿”，点击“帮我写歌词草稿”。先修改歌词，再点击生成歌曲；生成时使用的是你最终确认的文本。

歌词草稿由 ACE-Step 的轻量语言模型生成。本机三次真实试验均能返回中文歌词，但存在偏题、篇幅过长的情况，不能当作可靠的成品词作。建议保留合适句子，再按主题改写成四到八行，用 `[Verse]` 标注主歌、`[Chorus]` 标注副歌。歌曲模式开启语言模型的演唱规划，并明确要求按中文歌词演唱；默认描述强调清楚的普通话辅音和元音、自然分句换气、突出主唱与较轻伴奏，保留你填写的歌词和音色选择。用户已确认 12 号对照小样比上一版咬字更清楚、也更自然。生成后的演唱仍可能漏字、读音不准或不完全符合节奏，需要试听筛选；完成状态只代表音频已保存，不代表唱词和音色已验收。

## 保存与恢复

页面文件迁移已在 2026-10-11 重启后核验生效：D 盘活动页面文件为 34GB，C 盘旧文件已不存在。正式启动器已采用经过真实生成测试的 INT8 主模型常驻显卡配置，保留自动写词模型。30 秒 BGM 已成功生成；歌曲早期样本虽然可播放，用户反馈没有演唱，随后修正演唱请求，用户已确认 07 号对照小样能听到演唱。示例保存在“示例音乐”目录，参照其中的“试听顺序.md”选择；原有示例和失败记录保留。生成时尽量减少其他高占用应用，给模型留出系统内存余量；本机有限小样通过不代表所有时长、乐器和负载都已验证。

歌曲可选择男声或女声，以及清亮、温暖、沙哑、轻柔气声、有力量等音色。歌曲和 BGM 都可选择最多三种主要乐器：钢琴、木吉他、电吉他、弦乐、贝斯、鼓组、合成器、古筝、长笛。不选则交给模型编配；BGM 始终按纯音乐生成。

这些选择通过生成描述传给 ACE-Step，是音色和配器偏好，并非固定歌手或独立乐器轨道。实际声音可能不完全符合选择，请生成后试听筛选。选项随浏览器草稿保存，作品卡片显示所选偏好，“沿用这个想法”会恢复选择；以前的作品默认由 AI 选择。

- 浏览器保存当前表单草稿；作品、歌词和任务记录保存在交付目录的 `作品数据`。换浏览器不会带走草稿，但配对后能看到电脑上的作品。
- 每次只运行一个音乐生成任务；写词期间也会避免启动其他模型运算。页面刷新或退出设备不会取消已经提交的任务。
- 连接中断时保留任务编号，优先恢复查询，不自动重新生成。出现“核实后解除等待”时，先确认电脑上的模型已经完成或停止原任务，再解除等待。
- 正常退出请在启动窗口按 Ctrl+C。正在生成时停止电脑服务可能中断作品；先等当前作品完成更稳妥。
- 若启动窗口报告端口已占用，先检查是否已经启动。不要反复打开多个窗口。

## 开发与证据范围

工作台只使用 Python 标准库；ACE-Step 在 `runtime/ACE-Step-1.5/.venv` 中独立运行，模型和缓存也在 `runtime`。启动时检查模型权重齐全，并让 Hugging Face 模型加载使用本地文件。官方基础包还要求默认 1.7B 语言模型文件存在，但本机写词选择较轻的 0.6B 模型。`scripts/run_engine.py` 调用上游官方 INT8 量化；主模型常驻显卡，其他组件按需加载，使用同步 CUDA 执行。若量化静默退回完整精度，启动器会明确失败，不带着高内存配置继续运行。写词和生成串行执行。本轮没有安装新依赖或修改上游模型源码。安装包依赖本机 Python 基础运行时，不能保证把整个目录复制到另一台电脑就可运行。

源码入口为 `python -m app.server`；局域网加 `--lan`。集成启动入口 `python scripts/start_music.py --runtime <runtime目录>`。使用 `--local-only` 仅允许本机工作台访问。

接口模拟测试只证明应用流程；手机宽度浏览器检查不等于安卓实机验收。实际生成测试和剩余限制见正式交付目录中的验证报告。

## 界面配色

顶部“配色”可以切换雾蓝、浅紫、海盐绿、暖杏、樱花粉五种浅色外观。默认雾蓝，保留音乐工作室和动效；浏览器允许本地存储时会记住选择。每台设备分别选择，切换配色不会重新生成或中断试听。
