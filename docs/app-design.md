# Music Creator 中文创作工具设计与实施计划

日期：2026-10-11。延续用户已选定的方案：ACE-Step 独立服务，中文浏览器工作台，电脑生成、安卓浏览器操作。

## 结果与完成标准

写歌和 BGM 两个入口；说明主题/用途、风格、时长；歌曲可填歌词，也可主题写词后自行修改；提交后显示真实排队/生成/失败状态；作品持久保存、试听和下载。移动端适配。先支持家庭局域网；手机外网访问需另行明确部署权限。用户已批准独立安装模型与依赖，并进行真实歌曲和 BGM 测试。

## 设计

- Python 3.11 标准库服务 + 静态 HTML/CSS/JS，不给工作台额外增加依赖；ACE-Step 独立进程，仅监听本机。
- SQLite 保存任务与结果；单个生成任务工作线程，限制显存并发。前端重复提交携带幂等 ID；超时或结果不明不自动重复提交。
- 采用官方异步 API：release_task → query_result → v1/audio。模型输出复制到本地作品目录；只允许从配置的本机模型服务下载规定音频路由。
- 手机用配对码登录；会话 cookie；跨站写入校验；不将模型密钥暴露到浏览器。第一版不提供公网端口转发。
- 模型断线时保留输入、解释原因；任务恢复优先查询已知 task_id。停止网页不删除作品，不假装中断已提交的 GPU 运算。
- 默认 30 秒小样，歌曲建议选择 60 秒，batch_size=1，2B turbo、轻量 LM/PT/CPU offload 配置；不自动升级 XL。
- 视觉采用蓝灰工作台、浅色编辑纸面、暖黄色播放标识；桌面左侧创作、右侧作品，手机上下排列。字体使用系统中文字体，不依赖在线字体。

## 实施顺序

1. app/adapter.py：输入验证、ACE-Step 请求/状态/音频解析；tests/test_music_app.py 覆盖歌词/BGM参数、错误、上游下载地址限制。
2. app/storage.py、app/server.py：持久任务、幂等请求、断线恢复、单并发、配对认证、音频Range下载；测试模拟模型全流程及失败。
3. app/static/：可访问中文表单、模式切换、预设、草稿、任务列表、试听、下载、配对；检查桌面与390px视口。
4. 启动脚本和 docs/app-quickstart.md：清楚区分工作台与模型；模型未安装时给出可操作提示。
5. 相关测试、聚焦差异审查、安装获批后的真实歌曲/BGM测试。安卓实机需真实设备证据，否则明确待验。
6. 完整源代码、启动入口、验证报告保存至 D:/codex交付/2026-10-11/Music-Creator创作工具 并核验。此次不自动push或合并先前PR。

## 证据边界

模拟接口测试证明接入逻辑，不证明音乐音质。浏览器窄屏检查不等于安卓实机。没有模型真实成功输出时不能称完整生成流程验收通过。

## 2026-10-11 音乐工作室界面升级

用户反馈：原界面缺少音乐制作感，希望增加动画；配对码含义和位置不清楚。

设计落实为深色录音台，石墨背景 #101318、面板 #1b2028、薄荷绿 #80ddc5、淡紫 #b6a6f5、琥珀 #f3bc77。中文系统字体负责操作文字，Bahnschrift 负责品牌，Consolas 负责播放时间。控制台轨道是音乐主题装饰，生成和播放标签来自真实状态。

配对页用唱盘插画和可展开说明解释临时通行码及启动窗口位置。歌曲/BGM 操作不新增依赖。播放器提供单曲播放、暂停、键盘进度条、真实时间，播放事件驱动唱片旋转和 Web Audio 实时声音波形；降级时保留试听和进度，不伪装成真实频谱。暂停/结束停止动效，减少动画偏好关闭连续装饰与波形动画，页面隐藏时减少动画消耗。轮询保留播放器，卡片销毁时清理事件和音频图。

本次验收为助手浏览器自测，使用既有真实音频；不再次消耗显卡生成歌曲，不声称真实用户视觉接受或安卓实机验收。需检查配对、两曲播放互斥、暂停、跳转进度、歌词替换取消、桌面/手机溢出、浏览器错误和交付副本。

## 2026-10-11 五种浅色配色

用户明确要求不使用纯黑 UI，并增加颜色选择。默认改为雾蓝灰，另提供浅紫、海盐绿、暖杏、樱花粉；顶部原生选择框切换，允许列表校验，浏览器本地保存。控制台、面板、输入框、按钮和实时波形跟随主题；不改变音乐任务和认证。五种切换、刷新恢复、播放中切色、390px 手机入口均完成助手自测；无横向溢出或浏览器错误，未再次生成音频。直接复核此次 HTML、CSS 和主题相关 JavaScript 差异，未发现具体缺陷。

## 2026-10-11 人声与主要乐器

歌曲增加男声、女声和清亮、温暖、沙哑、轻柔气声、有力量等演唱偏好；歌曲/BGM 共用九种乐器，最多三种，不选时自动编配。浅色主题中的乐器按钮使用原生复选框，选满后仅禁用未选项，已选项仍可取消。配器不是独立轨道控制，UI 明确要求试听确认。

服务端允许列表校验、排序归一化和 BGM 人声清除；偏好进入作品记录、幂等指纹及 ACE-Step caption。旧作品字段默认自动且兼容旧指纹重放。浏览器草稿保存、作品偏好摘要与沿用功能同步支持新字段。此次 8 项聚焦回归通过；审查修正模式两侧空白归一化后，相关 BGM 测试再次通过。390px 浏览器自测通过；安卓实机和主观音色质量尚未验收。
