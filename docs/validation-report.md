研究内容核查日期：2026-10-09（UTC）。校验器加固日期：2026-10-10（UTC）。验证对象是研究仓库文件，不是上游音乐软件或模型。19项研究数据、来源与许可文字均未因本次工程修复而更新。

## 校验器范围

- Python 3.9+ 标准库，无依赖安装、无网络请求
- 顶层字段、整数版本1（拒绝布尔值）、非空范围、19条项目对象、完整字段及类型、唯一ID、真实ISO日历日期、布尔值与枚举
- HTTPS来源格式及项目内来源去重；JSON/CSV逐字段一致
- sources.csv每个URL恰好出现一次；project_ids必须精确等于引用该URL的项目集合，拒绝空、重复、遗漏或错误归属；检查来源类别与日期
- CSV表头不得缺失、重复或额外；行宽、引号语法与UTF-8均需有效。JSON重复键、损坏JSON、缺文件等失败均返回1和FAIL诊断，不打印traceback
- detail_document须为仓库内现存文件；拒绝绝对路径、Windows驱动器路径、反斜线、任何..路径段，以及解析符号链接后逃逸。允许指向仓库内文件的符号链接
- 校验器内部枚举Markdown文档时统一转换为POSIX斜杠路径再做可移植性检查，Windows反斜杠不再造成内部文档误拒；对外部输入（detail_document与Markdown链接目标）的上述防护保持不变
- 普通模式与Python优化模式（-O）执行同样校验，不用assert执行输入校验

## Markdown支持范围

离线轻量检查器，不是完整CommonMark/GFM解析器：

- 单行内联链接及图片，含空标签、尖括号目标、百分号编码路径、平衡括号路径与可选标题
- 完整引用、折叠引用，以及存在定义的简写引用；标签忽略大小写并折叠空白。完整/折叠引用缺定义时报错；未定义的普通方括号文字按正文处理
- 单行引用定义；相同标签采用首个定义。只检查实际使用的引用，不将未使用定义当作链接
- 相对文件链接，以及本页或其他Markdown文件的标题锚点；中文标题、常见强调/代码/链接标题、ATX与Setext、重复标题的-1/-2后缀
- 忽略围栏代码块、缩进代码、单行行内代码与HTML注释内的链接示例；支持单层列表/引用中的围栏。外部http、https、mailto和协议相对链接不发网络请求、不校验远端锚点
- Markdown相对路径可用..返回父目录，但解析后必须仍在仓库内且是文件；不允许绝对文件链接、仓库外符号链接或对非Markdown文件校验片段锚点

边界：不支持原始HTML链接/自定义id、多行引用定义、多行行内代码、复杂嵌套的列表/引用或嵌套方括号标签；不保证所有Unicode符号的锚点都与GitHub渲染器完全一致。此类写法应改成上述受支持的简单Markdown并补回归用例，或人工复核；不能把检查通过当作完整渲染验证。

## 可复现命令

从仓库根目录运行：

```sh
python3 scripts/validate_catalog.py
python3 -O scripts/validate_catalog.py
python3 -m unittest discover -s tests -v
python3 -O -m unittest discover -s tests -v
```

测试复制实际研究目录到临时目录，不修改19项原始数据；每个用例用独立子进程覆盖普通及-O模式，并同时断言退出码、PASS/FAIL及无traceback。覆盖真实目录、JSON结构/版本/日期/类型、来源归属、坏CSV、缺文件、symlink逃逸、Markdown失效路径/引用/锚点及有效代码示例。符号链接相关用例依赖真实能力探测（实际创建并读取一条符号链接，不按平台名猜测）：仅当探测确认主机不允许创建符号链接（如Windows无开发者模式或SeCreateSymbolicLink特权）时跳过，跳过必须携带探测返回的具体原因；其他I/O错误按测试失败暴露，不吞掉、不误标为跳过。路径防护（绝对路径/越界/反斜杠/目录/缺失文件）与闰日校验不依赖符号链接能力，在任何主机都执行；含嵌套子目录Markdown文档在Windows反斜杠路径下被正常发现并校验的回归用例，以内部链接计数变化证明文件确实被扫描。
