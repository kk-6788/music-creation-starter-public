# 来源、核查日期与研究方法

## 研究范围

核查日期为 **2026-10-09（UTC）**。共19个项目/版本条目：10项AI音乐/歌声方向、9项交互工具/开发组件。不同版本单列是因为部署与许可边界不同；DiffRhythm 1.2与2不能互换，YuE当前主线与旧YuE分支也不能混写。OpenUTAU作为DiffSinger配套界面介绍，没有完成同深度的独立条目审查。

关注零基础用户能否形成闭环：写词、做旋律、编伴奏、自己唱或合成歌声、保存结果。并非穷尽所有音乐软件，也没有商业闭源服务价格比较；未以GitHub星数作为质量或适用性依据。

## 证据来源与使用方法

1. 优先官方仓库README、实际入口/配置、安装文档、LICENSE/模型专属许可、官方模型卡
2. 硬件数值保留适用模型、精度/offload等条件；没有统一最低显存就明确未提供，不猜数字
3. 中文支持分别检查界面词条、歌词/语言声明、音素设置；中文质量必须试听，但本次未做试听
4. 许可证拆成代码、权重/声库/素材、输出。未填写许可不等于可以自由使用
5. 各条目原始官方链接位于[AI研究](ai-generation.md)和[交互研究](interactive-tools.md)，也保存在[JSON](../data/projects.json)的sources中；[来源索引](../data/sources.csv)可用于维护
6. SongGeneration官方入口在研究读取中出现404/401，汇总阶段复查仍不可读；社区镜像仅用于标注历史信息，不能替代当前官方状态和授权

汇总时再次直接读取MuLaCover MODEL_LICENSE、YuE2 MODEL_LICENSE与ACE-Step1.5模型卡，确认高风险许可差异。该抽样复核不是对全部组件的法律审计。

## 事实、判断和缺口

- “模型卡标有zh”“已有中文词条”“README称需要24GB”属于文档事实
- “适合新手先尝试”“更适合第二阶段”属于基于流程复杂度的编辑判断，不是实测评分
- “听感好”“中文准确”“速度快”“消费卡稳定”需要运行数据，本次不作此类保证
- 未安装软件、下载模型、执行推理、提交在线生成、录音、试听、注册或付费
- 未验证在线演示实时额度、排队、收费、地区可达性以及完整服务隐私条款
- 未审计全部依赖、训练数据、声库授权或输出侵权相似性
- 未锁定上游commit；来源URL多数指向可变分支或模型主页，日后内容可能改变。用于产品前应补充版本快照

## 维护状态怎么读

交互研究中的推送日期来自GitHub API pushed_at：仅表示仓库发生推送，不等于正式版发布时间、活跃用户量或质量。AI研究保留具体README发布记录，不把未读取的最近提交日期写成事实。Chrome Music Lab已归档仅说明该公开代码仓库状态，不代表线上实验已关闭。

## 来源可信度标签

JSON evidence_level为official-document-review表示条目主要根据官方文档；official-access-blocked-secondary-history表示官方不可读、只能保留历史旁证。sources列出条目用到的页面，不表示每个URL都是许可页，也不表示所有页面在未来持续可用。

来源索引的source_kind按域名/已知项目关系标记；SongGeneration社区镜像和社区模型卡标secondary-community。其余标primary-or-official-reference，论文作为作者公开研究证据。外站可用性不由本仓库离线验证脚本检查。
