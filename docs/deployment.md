# 部署与使用门槛

核查日期：2026-10-09；以下为官方文档条件，不是安装成功或性能实测。版本和平台依赖会变，实际动手前打开对应官方说明。

## 优先级：先用成品，再考虑搭建

| 场景 | 合适入口 | 需要什么 | 不应承诺什么 |
|---|---|---|---|
| 今天先玩 | BeepBox / signal / Chrome Music Lab | 现代浏览器、可播放声音 | 不承诺所有实验完全离线或所有浏览器相同 |
| 本地录唱/编曲 | Audacity / LMMS / Hydrogen 官方发布包 | 支持的桌面系统；录唱另需麦克风 | 不要求用户编译源码；不承诺LMMS内置录麦克风 |
| 在线AI体验 | ACE-Step / HeartMuLa官方README链接的服务 | 网络，可能需账户/排队/付费 | 本次没有验证当前额度、队列、可用性或隐私条款 |
| 本地AI推理 | 按下表逐项评估 | Python环境、模型下载、存储、GPU或其他后端 | 免费权重不等于零硬件成本；支持CPU不等于实用速度 |
| 开发自家网页 | Tone.js / wavesurfer.js | 前端开发、音频调度、浏览器权限处理 | 两个库不会自动组成完整DAW或AI作曲器 |

## AI本地路线：不要混用显存数字

| 项目 | 已读到的条件 | 仍需确认 |
|---|---|---|
| ACE-Step 1.5 | Python3.11–3.12；普通DiT可量化/offload；≤6GB档默认关闭LM；XL≥12GB优化、≥20GB更合适 | 具体checkpoint/后端/精度/时长的速度与峰值内存；普通turbo不含所有base能力 |
| HeartMuLa | CUDA示例；主模型、codec、配置/tokenizer；支持lazy loading | 官方未给统一最低显存；不能推断8GB必跑 |
| YuE2 | Linux、Python3.12、支持BF16的NVIDIA、官方起点24GB | 不同长度和模型组合的内存；参考录音还需额外流程 |
| DiffSinger | 引擎Python≥3.10，推荐PyTorch≥2.4；ONNX部署路径 | 具体声库/声码器/音素器兼容性；OpenUTAU现成声库路线与引擎训练不同 |
| DiffRhythm 1.2 | espeak-ng；base最低8GB须chunked | full模型不能沿用8GB门槛；LRC歌词准备 |
| DiffRhythm 2 | espeak-ng、Python；自动下载权重及其他组件 | 统一最低显存未明；Gradio等功能仍待办 |
| MuLaCover | Linux NVIDIA/Python3.10，多组权重；音频参考还需转写/和弦工具 | 已验证B300不是消费卡最低需求；输出非商用 |
| SongGen | Python3.9、CUDA≥11.8示例，X-Codec | 模型许可与实际显存；仅英文最长30秒 |
| MusicGen | Gradio/Jupyter/Colab；medium官方建议16GB GPU | small和短段可能更低但未实测；权重非商用 |
| SongGeneration | 官方入口本次不可读 | 暂不提供安装配方；镜像历史数字不能保证现在能运行 |

详细来源集中在[AI研究](ai-generation.md)，前端/桌面工具构建说明在[交互工具研究](interactive-tools.md)。

## 如果之后要真正安装

1. 只选一个项目和明确模型版本，核对下载大小、剩余磁盘、GPU型号/显存、驱动和操作系统
2. 从官方仓库和作者指定模型源下载，固定版本/commit/revision；不要让多个项目共享一个随意升级的Python环境
3. 先读安装脚本、模型自定义代码与依赖来源，再运行；需要执行远程自定义代码时了解其信任边界
4. 只用少量非私密原创输入跑官方最小示例，记录耗时、峰值内存、报错和输出
5. 显存不足先缩短时长/尝试项目支持的offload或chunked方案；不要删改系统驱动来“碰运气”
6. 不把开发用Gradio端口直接公开到互联网；公开服务前需认证、限流、配额、日志脱敏和上传安全检查
7. 成功后记录可重复步骤，失败也记录环境与版本。当前仓库未执行以上模型测试

不提供“一键装齐19项”的脚本：项目目标、许可与环境冲突不同，初学者先完成作品比维护十几个模型环境更有价值。
