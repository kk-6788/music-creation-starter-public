# 零基础谱曲：把心里的调子变成音符

写词有[避坑清单](../examples/lyric-anti-patterns.md)，谱曲的零基础路径是本文：不学五线谱、不学乐器，三条路把旋律做出来。写完接[完整歌曲路线](complete-song.md)。

核查日期：2026-10-10。工具能力描述来自官方 README 与产品页，未做生成实测。

## 先明白一件事：旋律不是"想"出来的，是"哼"出来的

零基础最常见的卡壳是盯着空白编辑器等灵感。真实流程反着来：**先哼出来，再记下来**。你的嗓子就是你的乐器，哼唱录音就是你的草稿纸。下面三条路线都从这个思路出发。

## 路线一：哼唱转谱（推荐第一条走）

用 Spotify 开源的 Basic Pitch：把哼唱、口哨、甚至随便弹的钢琴录音，自动转成 MIDI 音符。

流程：

1. 手机录音：把副歌那句词**按词的声调**哼 20–30 秒，重复哼两三遍（给模型更多素材）
2. 打开 [basicpitch.io](https://basicpitch.io)（官方在线版，浏览器直接用），上传录音
3. 下载转出的 MIDI 文件
4. 用 [signal](https://signalmidi.app/edit) 打开 MIDI：能看到每个音的音高和位置，唱跑的地方拖一拖修正
5. 在 signal 里配上和弦（用[和弦速查](complete-song.md)的四组万能进行），换音色（见[乐器与音色](instruments.md)），试听，导出

要点：
- 哼的时候**带节奏感**（跟着点头的速度哼），转出来的音符才不会稀碎
- 一次只哼副歌 4 行。主歌可以等副歌定了再配
- 转换结果通常 80% 可用，剩下 20% 在 signal 里手动修——修的过程本身就是学乐理最快的路径
- basicpitch.io 会把你上传的音频发给服务器处理，**不要传私密录音**；介意的话本地安装 `pip install basic-pitch`（代码 Apache-2.0）

为什么这条路排第一：它是唯一让「完全不懂音符」的人从零产出自己旋律的路，而且旋律真的是你自己的，不是 AI 给的。

## 路线二：网格点音符（要更多控制时）

[BeepBox](https://www.beepbox.co/) 的格子界面本身就是零乐理谱曲器：横轴时间、纵轴音高，点一下就是一个音。技巧：

1. **用五声音阶开场**：把音高限制在 C-D-E-G-A 五个音（宫商角徵羽）。这五个音两两之间怎么连都不难听，天然带中文民谣感，是零基础写中文歌的作弊码
2. **节奏先于音高**：先在一行里点出节奏型（比如"短-短-长"），确认摇头晃脑成立，再把音符上下拖动调音高
3. **问答句结构**：前两小节一个上行的"问句"，后两小节一个下行的"答句"。句尾落在 C（do）最稳，落在 A（la）带一点忧郁
4. 4 小节旋律 → 复制成三段 → 每段只改结尾一两个音，就是[30秒路线](first-30-seconds.md)的加强版

## 路线三：让 AI 出旋律，你当裁判

用 ACE-Step 1.5 生成几版，**不生成整歌，只用它的旋律骨架**：

1. 用你的歌词+「纯音乐/器乐版」风格提示生成 3 版
2. 回听，把最顺耳那版的旋律用手机跟着哼熟
3. 有了哼唱，回到路线一/二把它精确化

这条路的边界：AI 生成的旋律容易"顺但没记忆点"，当跳板可以，当作品核心会平庸。判断标准还是那个——哼完第二天你还记得住吗？

## 旋律变好听的三个零理论技巧

不管走哪条路线，改稿时用这三招：

1. **重复**：好听的句子重复第二遍，只在结尾变一个音。流行歌的洗脑全靠这个
2. **模进**：把一句整体往上挪两个格再唱一遍（BeepBox 里框选+拖动）。立刻有"推进感"
3. **留白**：一小节只放 2 个音比放满 8 个音更有气质。删到不能再删为止

## 按普通话声调定旋律走向（中文歌专属）

普通话四个声调天然带音高方向，逆着写会唱出怪腔：

- 一声（高平）：平音或长音，别上下滑
- 二声（上扬）：音往上走
- 三声（降升）：低起或带一点下落再回升
- 四声（下降）：音从高往低走

例："回家"（回=二声，家=一声）→ "回"的音比前一个音高，"家"保持平或再高一点。副歌核心句尤其要过这一关。

## 三条路线怎么选

| 情况 | 走哪条 |
|---|---|
| 完全零基础，今天就要一段自己的旋律 | 路线一（哼唱转谱） |
| 想自己控制每个音符、做出编辑乐趣 | 路线二（网格+五声音阶） |
| 有歌词但哼不出满意的调 | 路线三（AI 出骨架）再回到一/二 |

验收：旋律能跟着哼而不卡壳；第二天还记得住副歌；词的声调和音高方向不打架。之后进[完整歌曲路线](complete-song.md)做结构。
