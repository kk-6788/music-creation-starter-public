# 作品记录模板

- 标题与主题：
- 日期：
- 使用路线：手工 / AI / 自己录唱
- 工具版本或commit：
- 模型完整ID与revision（如适用）：
- 硬件、系统、精度/offload配置（如适用）：
- 歌词版本与风格提示：
- BPM、拍号、时长目标：
- seed与关键参数（如适用）：
- 输入素材来源及许可链接：
- 声音/参考录音授权情况：
- 当前用途：私人练习 / 公开分享 / 商业发行
- 实际耗时、失败或重试次数：
- 实际导出文件格式、采样率、声道、时长：
- 听感问题：漏字 / 多字 / 发音 / 节奏 / 人声音量 / 削顶 / 收尾
- 这次只修改了什么：
- 下次保留什么、改什么：
- 工程文件与最终音频保存位置：
- 发布前许可核查完成情况：

本模板是待填写表单，不是一次已经成功的生成记录。不要把密码、API密钥或私密原始录音放入公开仓库。
