# 中文歌词避坑清单（AI协写时代版）

让 AI 帮你写歌词时，它最容易产出"一眼假"的词。本清单用于写完之后逐项自查，也用于给文字助手的提示词里直接粘贴"禁止"部分。灵感来自英文 Suno 社区沉淀的反模式经验，按中文写作习惯重写。

## 一、空泛大词（出现即改）

岁月、时光、远方、梦想、星辰大海、心中的光、永恒、命运、灵魂深处、无尽的天空

这些词放在任何一首歌里都成立，所以放在任何一首歌里都没有意义。改法：换成一个具体场景。"岁月流逝"改成"出租屋的墙上又多了一道划痕"。

## 二、万能形容词

无尽、永恒、破碎、闪耀、绽放、燃烧、绽放、深邃、温柔而坚定

形容词是感觉的二手货。删掉形容词，改成动作和名词："她很温柔"改成"她把伞往我这边偏了偏"。

## 三、翻译腔意象

王冠、锁链、灰烬、深渊、迷宫、铠甲、圣殿、迷雾中的灯塔、破碎的镜子、天使的翅膀

这些意象在英文歌词里有传统，直译到中文歌里就是违和的"AI诗"。中文歌的意象库应该是：巷口、阳台、外卖盒、地铁末班车、外婆的缝纫机。

## 四、押韵灾难

- 全曲一韵到底（尤其 ai、ang、ong 这三个大韵），三行之后开始腻
- 为了押韵硬凑词：句子本意是A，为了韵脚拐到B
- 韵脚词全是名词（心/情/命/明/星 连续出现）

改法：普通话写歌，**声调和节奏比韵脚重要**。副歌押韵可以松到只押一二处；主歌可以完全不押，靠行长和断句对齐节奏。

## 五、结构上的偷懒

- 主歌和副歌分不清（信息密度、行长、语气全一样）
- 副歌每次重复都在改词——副歌就是靠原样重复建立记忆点的
- 没有"具体的人、具体的事、具体的物件"，从头到尾都是情绪陈述

## 六、给文字助手的提示词模板

把这段直接贴给任何文字AI（配合[改词提示模板](first-song.md)使用）：

```text
请帮我写一首中文歌词。

主题：【一句话，比如"搬家那天发现前室友留下的东西"】
情绪：【一个词，比如"释然里带一点酸"】
结构：主歌1四行 / 副歌四行 / 主歌2四行 / 副歌重复 / 桥段两行 / 副歌重复
每行7–10个字。

硬性要求：
1. 每一段必须出现至少一个具体的物件或动作（如"半瓶防晒霜"），不许全段都是情绪词
2. 禁用词：岁月、时光、远方、梦想、星辰大海、永恒、无尽、破碎、绽放、王冠、锁链、灰烬、深渊
3. 副歌四行写完后原样重复，不许改字
4. 不追求押韵，优先念着顺口；写完你自己朗读一遍，标出拗口的地方
5. 桥段要和主副歌视角不同（比如主歌是"我"，桥段突然切到对方或多年后）
```

## 七、写完之后的三分钟自查

1. **遮住歌名**：把歌词发给一个朋友，让对方猜主题。猜不出=信息太抽象
2. **副歌测试**：只看副歌4行，这4行是不是全曲最想说的话？不是=副歌选错了
3. **朗读测试**：大声读一遍，卡壳的地方唱的时候也一定卡

记住：AI写的是初稿，你做的是删减和具体化。方向是"把通用改成只有你能写"。
